# Roteiros de Respostas (Media Training)

Diretório destinado a armazenar as propostas e roteiros de respostas desenvolvidos colaborativamente com o usuário.

## Regras Fundamentais

1. **Simulação/Preparação:** Todo o conteúdo aqui é uma proposta para treinamento, nunca uma fala efetivamente dita.
2. **Construção Colaborativa:** O usuário define o tom, a direção e as prioridades.
3. **Oralidade:** Foco em linguagem fluida, argumentos claros e impacto na fala falada.
4. **Checagem Prévia:** Sinalizar expressamente qualquer dado ou número que precise de confirmação factual antes do uso.

Consulte o modelo em `.agents/templates/roteiro_resposta.md`.
